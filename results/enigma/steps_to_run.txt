Run these commands from the repository root.

1. Copy the files from fixed_files into the same paths in your repository.
2. Create a virtual environment: python -m venv .venv
3. Activate it with .venv\Scripts\Activate.ps1 on Windows PowerShell, or source .venv/bin/activate on macOS and Linux
4. Run the application: python main.py
5. Run the tests: python -m unittest discover -s .
